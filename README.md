# Azhar Portfolio

A modern personal portfolio website showcasing my projects, skills, education, and journey as a Computer Science Engineering student.

## 🌐 Live Demo

Add your portfolio link here:

https://azhar-portfolio-nine.vercel.app/

## 🚀 Features

* Modern and responsive design
* Animated hero section with typewriter effect
* About Me section with learning highlights
* Education & Journey timeline
* Interactive Skills section
* Featured Projects showcase
* Contact section with social links
* Smooth animations using Framer Motion

## 🛠️ Built With

* React.js
* Tailwind CSS
* Framer Motion
* Vite
* Lucide React

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/AtifKhalji/azhar-portfolio.git
```

Navigate to the project:

```bash
cd azhar-portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
